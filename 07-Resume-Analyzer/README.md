# Resume Analyzer

## Overview

An AI-powered Resume Analyzer built using:

- Google Gemini
- ChromaDB
- Streamlit
- PyPDF

## Features

- Upload Resume PDF
- Extract Resume Information
- Resume Summary
- Skills Analysis
- Project Analysis
- Career Recommendations

## Example Questions

- Summarize my resume
- What are my technical skills?
- What projects have I completed?
- What jobs match my profile?
- What are my strengths?

## Technologies Used

- Python
- Streamlit
- ChromaDB
- Google Gemini
- PyPDF
